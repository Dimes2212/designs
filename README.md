# Система записи клиентов в парикмахерскую

Учебный проект мобильного интерфейса системы записи клиентов в парикмахерскую.

Проект выполнен в рамках практических заданий по дисциплине:

> «Методы и средства проектирования информационных систем и технологий»

---

# Описание проекта

Данная система предназначена для автоматизации процесса записи клиентов на услуги парикмахерской.

Интерфейс приложения позволяет:

- регистрировать клиентов;
- просматривать список мастеров;
- выбирать дату и время записи;
- управлять существующими записями;
- получать уведомления;
- работать с расписанием мастеров;
- администрировать записи клиентов.

Проект разработан на основе:

- функциональных требований;
- нефункциональных требований;
- Use-Case диаграммы;
- диаграммы классов;
- User Stories.

---

# Основные возможности системы

## Возможности клиента

- регистрация и авторизация;
- просмотр услуг;
- выбор мастера;
- просмотр свободного времени;
- создание записи;
- перенос записи;
- отмена записи;
- просмотр уведомлений.

---

## Возможности мастера

- просмотр расписания;
- просмотр списка клиентов;
- просмотр информации о предстоящих услугах.

---

## Возможности администратора

- управление записями;
- изменение времени записи;
- отмена записи;
- просмотр клиентов.
